# 预实验协议与解释边界

## 研究问题

H1：在独立质量过滤与预先设定的配对约束下，较大的表示残差异常分是否带来较高的键控读出覆盖率？

H2：这种候选是否改善有限搜索预算下随机消息的完整交付与精确恢复？

这不是“outlier 能否替代 AES”的安全实验，也不是 token embedding 中 glitch token 的普查。实现分析的是**整句改写在冻结 LLM 隐藏表示中的异常偏移**；它是原始想法的一个可操作代理。

## 特征与拟合

`f(y) = normalize(mean(H_last(prefix || y)[text positions]))`。

`behavior_dist = 1 - f(x)^T f(y)`。

独立 MiniLM 定义 `sem_dist`。混杂变量为 `sem_dist, nll_mean, n_tokens, edit_ratio, zipf_mean, nli_min`。

`edit_ratio` 为小写单词序列 SequenceMatcher 的 `1-ratio`，不是严格 Levenshtein 距离。`zipf_mean` 来自 wordfreq 的英文单词 Zipf 频率，不能完全控制 token 稀有度。NLL 是固定前缀下 plain-text 的逐 token 交叉熵；这是同一公开 LM 的自然度代理，**不是生成候选时带 prompt、temperature、top-p 的真实 proposal 概率**。

只用通过过滤的 dev 候选拟合标准化、二阶多项式展开、固定 alpha=10 的 ridge。残差：`O(y;x) = behavior_dist - predicted_behavior_dist`。不使用 key、目标比特或覆盖率训练。dev 的残差是 in-sample，只用于开发与拟合，不作有效性证据。正式解释仍受 nuisance 模型设定影响，匹配分析不是随机因果实验。

## 配对与选择

每个原句最多32次生成；质量合格且去重后有 n 个候选。令 K=8。若 n<2K，记选择失败。高异常候选池取排名最高的 `min(max(K, ceil(0.25*n)), n-K)` 个，其他作为普通控制池。

在两池间做有卡尺约束的二分图匹配；先最大化有效配对数，再最小化标准化距离。若至少有 K 对，按匹配距离保留最接近的 K 对；否则全组不可用。**因此研究对象是具有共同支持的高异常候选，不能外推到所有异常候选。**每对六个绝对差都不超过配置卡尺；报告最终均值差。边际平衡不等于整个联合分布严格相同。

`random` 从同一合格池不放回抽 K 个；`nearest` 取 sem_dist 最小的 K 个。所有选择在读出规则/目标比特之前完成。辅助组可与其他组重叠，outlier 和 matched 两组互斥。

## 读出与覆盖

HMAC-SHA256 对 nonce、块编号、位编号作域分离，SHAKE256 展开成归一化 Rademacher 方向。每个方向阈值是 dev 原句特征投影的中位数。

`D_j(y)=1[r_j^T f(y) >= tau_j]`。

`gamma(y)=min_j abs(r_j^T f(y)-tau_j)`，因方向单位化，这是欧氏特征空间间隔。编码时要求 gamma 大于配置间隔。它不是任意保义改写下的保证。有限采样覆盖的不同符号数除以 `2^bits` 是均匀目标下的单块可编码率；完整覆盖率是所有符号都可找到。

阈值只近似平衡校准集合的每个边际比特，不保证联合符号概率、给定某个原句的局部候选分布、或测试领域都平衡。若一组候选聚在同一个投影区域，即使8个候选也只有1个可用符号。这种失败应保留。

## 分布代理与检测

仅在选择后的有限候选池定义 `p_i = softmax(-NLL_sum_i)`。对均匀目标符号，在满足间隔的同符号候选中按条件 p 采样；缺失符号中止。`pool_proxy_tv_success` 是成功条件下输出分布与这个 p 的 TV；`target_abort` 单独报告。

这个 TV 忽略了从真实语言分布进入候选池的偏差，也没有把真实旁观者的全部侧信息建模。它不能用于任何全局不可检测性声明。若偏差大，说明即使这个弱代理也不平衡；若偏差小，不能说明整体安全。

检测器仅为字符 n-gram TF-IDF + 固定 C 的逻辑回归。训练用 dev 的前半实验 key seeds，测试用 test/OOD 的后半 key seeds。自然对照来自同一方法的有限候选池与同一 NLL 权重，检测结果只回答**池内编码选择**的可检测性，不能说明相对真实自然文本的不可检测性。仅纳入成功目标形成成对 cover/stego；报告接受样本数。后续需增加公开 embedding 检测器、独立自然文本、攻击者知晓算法且可见足量样本的协议。

## 消息协议

真实通信使用随机 32 字节 master key，HKDF 分离 coding/AEAD 用途；每帧随机 nonce。实验评测使用公开 seed 导出的 key，仅用于重现读出几何，不应作部署密钥。

原句按公开 nonce 派生的顺序排列、循环使用，顺序与比特无关；不同 trial 因 nonce 不同覆盖不同原句，避免短消息永远只测试列表前几句。每个块只尝试所属原句的既定候选组。没有目标相关的公开 retry index、没有跳过失败原句、没有传候选位置。一次失败则不发送整帧。载体使用显式 JSON 数组分块，重排、插入、删改和自由改写不在本次正确性保证内。

接收方只从收到的文本重新计算 f(y)。profile 包含公开校准特征和指纹，不能含候选文本到比特的秘密查找表。raw 解码无认证；正确性由本地对原始字节比较验证。AEAD 模式对恢复的密文和帧头验证，失败不输出明文；不保证每一处载体文本改写都触发失败，例如同一码字的等价载体可能恢复相同消息。

不同硬件/数值内核可使边界附近比特不一致，因此必须固定环境并运行 fresh-forward 检查。间隔保护降低数值风险，但不提供跨硬件定理。

## 统计、成本与预先决定

- 主设置：1 bit，margin=0.0001；其他是次要敏感性分析。
- 配对来源 group 和 key 两个维度重采样；同一原句改写不是独立观测。同一较大来源的原句应共享 group_id。
- 两维 bootstrap 是探索性不确定性估计，不含重新生成语料、重新拟合 nuisance、多个模型选择引入的全部不确定性。
- 不能看完测试集结果再把最优 layer、margin、key、filter 当成固定方法。
- 所有匹配失败原句在总体覆盖率中计零，同时报告匹配子集结果与选择率。
- 净传输率分子只计整条成功恢复的原始消息比特；分母包括完整帧 JSON 的 tokenizer token。AEAD 标签通过更多载体句计入；帧头元数据本身也计入。
- 未发送的失败帧传输成本为零，但尝试数、消息恢复率和计算成本仍必须列出，不能借此掩盖大量失败。
- 共用候选池的生成、特征和语义评估成本在 costs.jsonl。各方法虽共享成本，也不能在“冷启动更快”的主张里省略它。
- 阶段计时不含模型下载、模型加载；codec-bench 不含提前建池。需要实际应用成本时另测完整进程 wall time 与峰值显存。
- 初始数据为编写的英文句子，语域较窄，自动语义过滤有误差。扩大至独立真实语料、第二模型和功能探针后才评估论文主张。

如果工程层验证正常但高异常分在匹配后没有稳定收益，应接受该结果。若自动过滤质量差或共同支持很少，先修复测量问题，不把无信息实验写成负面理论结论。
