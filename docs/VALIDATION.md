# 本次交付的验证范围

此文件说明“代码通过检查”和“研究假设得到支持”的区别。

## 已执行

- Python 全项目编译检查。
- 13 项核心单元/协议测试：位宽 1–8 的字节恢复、非零补位拒绝、key/nonce/块编号分离、间隔充分条件、有限池分布与中止率、开发集拟合限制、严格等预算匹配及失败、配对区间、独立接收方、AEAD 错钥拒绝、帧字段/块丢失检查、配置损坏检查、密钥禁止覆盖。
- 独立接收方测试在复制公开 profile 后**删除发送方目录**，再从载体文本恢复字节。
- 完整合成流程：36 个人工来源 × 32 个候选 = 1,152 个特征记录，覆盖生成后的选择、评测、报告、检测与绘图路径。
- 100 条合成载体重新提取特征，在 6 个 key、3 个 bit 上检查 1,800 个读出比特；本次为零错误。这个数字仅验证代码一致性，不说明真实 LLM 的可靠性。
- 合成随机消息 benchmark：执行多 trial、四个方法，检查失败保留、独立特征重算、字节比较与消息级汇总。结果标记为 synthetic，包含可能的编码失败。

## 没有执行

- 真实 Qwen、MiniLM、DeBERTa 权重的下载与推理：交付环境无 PyTorch/GPU/模型权重。
- 任何真实模型上的 outlier 优势、不可检测性、安全性或泛化结论。
- 真实 GPU 显存、吞吐、跨设备一致性与长消息性能测量。

模型加载、隐藏层提取、NLI 标签顺序和 AEAD 调用依据官方模型卡/文档实现。真实模型首次运行应按 README 的 12 句 smoke 步骤验证，再投入完整计算。

本地已验证的 CPU 依赖版本：Python 运行环境中的 numpy 2.3.5、scipy 1.17.0、scikit-learn 1.8.0、cryptography 46.0.0、PyYAML 6.0.3。项目中的依赖范围允许其他兼容版本，但不代表已逐一测试。

`examples/synthetic_smoke/` 只保留合成报告与汇总样例，便于识别输出格式。不包含任何实验密钥、私密数据或真实模型结果。
